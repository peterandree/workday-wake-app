# Contributing to Workday-Wake

Thank you for your interest in helping improve Workday-Wake!

## 🛑 Code Contributions
Workday-Wake is a **proprietary, closed-source** Android application. 
**We do not accept code contributions, Pull Requests, or reverse-engineered patches.** Any Pull Requests opened against this repository will be closed.

## 💡 How You Can Help

While the code is closed, this public repository serves as the official hub for community feedback, documentation, and issue tracking. You can contribute to the project in the following ways:

### 1. Reporting Bugs
If you find a bug in the Android app, please open a **Bug Report** in the Issues tab. 
To help us fix it quickly, please provide:
- Your exact device model (e.g., Realme Narzo 50)
- Your OS and OEM skin version (e.g., Android 14 / ColorOS 14)
- Clear, step-by-step instructions to reproduce the issue.
- Details of any battery optimization settings you have already applied.

### 2. Requesting Features
Have an idea to make Workday-Wake better? Open a **Feature Request** in the Issues tab.
Please explain the problem your feature solves and how you envision it working.

### 3. Improving Documentation
If you spot an error, typo, or missing information on our homepage or in our documentation, please let us know by opening an issue. 

---
By participating in this repository, you agree to communicate respectfully and constructively. Thank you for making Workday-Wake better!
